# Plan for Repository
## Goals
1. Successfully complete activity by creating and maintaining a GitHub Repository.
2. Store and organize the required files from Activity 14 (PDF and QMD).
3. Demonstrate proper GitHub workflow using branches, issues, commits, and pull requests
4. Keep the repository organized and easy to understand

## Needs
- Activity 14 PDF
- Activity 14 QMD file
- GitHub repository
- README.md file
- At least one additional branch besides main
- At least two issues for tracking tasks
- A pull request to merge work into main

## Steps

### 1. Create Repository
- Make a new GitHub named Activity15
- Add a README.md

### 2. Add required files
- Upload Activity 14 PDF
- Upload Activity 14 QMD

### 3. Create and Use Branches
- Create a branch called update plan
- Make edits on this branch
- Commit changes with important messages

### 4. Use Issues
- Create Issue #1: Add PLAN.md
- Create Issue #2: Review Activity 14 files
- Tag commits to issues when possible
- Close issues once completed

### 5. Make a pull request
- Open a Pull Request to merge update plan into main
- Add a title and description explaning the purpose
- Merge once all tasks are finished

### 6. Maintain the Repository
- Keep main branch up to date
- Use issues to track tasks
- Keep commit messages valuable
- Update READ.md for any future changes to repository
